# The lines for colvingardens.info's own .htaccess (in the site's top
# folder on GoDaddy), for when the static HTML pages replace the PmWiki
# site.
#
# Version
#   1.0 - 23 November 2026
#
# The pages keep the old site's names (index.php?n=Main.Achillea is now
# Achillea.html) and the pictures keep their old folder (Images/), so
# old links from bookmarks and search engines still arrive at the right
# page. The old copies of pages under a common name (Yarrow, Coneflowers
# ...) go to the page they copied; the beekeeping pages (older copies of
# BKBoK's, left out) go to bkbok.info, whose own .htaccess sends them on
# to the right page there. Every other old wiki address - including
# ?action=edit - goes to the Index.
#
# The publish script never writes .htaccess, so paste these lines in by
# hand: at the END of the existing .htaccess, or as the whole file if
# there is none (if it has a DirectoryIndex line, replace that one with
# the one below rather than having two).
